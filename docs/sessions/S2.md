# S2: Collector and LLM client
- `airflow_hook.py`: run the DAG, find the failed task instance, and read its log.
- `collector.py`: parse dbt `run_results.json` and `manifest.json` to get the failing node, the compiled SQL and the failing test. Diff the upstream schema (manifest/catalog against the last good run) and gather row-count and null-rate deltas from duckdb.
- `llm.py`: use the openai SDK against the Meta Model API (Muse Spark), falling back to Baseten `meta-models/muse-spark-open-1026` on error or timeout. Define a pydantic `Diagnosis` with root_cause, evidence, confidence, patch (unified diff), and action (fix or suggest). Retry once on invalid JSON and cache responses. Tests use recorded fixtures only.
