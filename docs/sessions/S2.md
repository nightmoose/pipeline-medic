# S2: Collector and LLM client
- `airflow_hook.py`: run the DAG, find the failed task instance, and read its log.
- `collector.py`: parse dbt `run_results.json` and `manifest.json` to get the failing node, the compiled SQL and the failing test. Diff the upstream schema (manifest/catalog against the last good run) and gather row-count and null-rate deltas from duckdb.
- `llm.py`: use the openai SDK against the Meta Model API (`https://api.meta.ai/v1`, `MODEL_API_KEY`, `muse-spark-1.3`) with no fallback provider. Define a pydantic `Diagnosis` with root_cause, evidence, confidence, patch (unified diff), and action (fix or suggest). Use `response_format` for JSON, retry once on invalid JSON, and cache responses. Tests use mock or recorded response fixtures only, so no key is needed.
