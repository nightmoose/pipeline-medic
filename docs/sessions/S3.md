# S3: Sandbox verification and PR
- `verify.py`: copy the dbt project and duckdb file into a temp sandbox, apply the patch, and run `dbt compile` then `dbt build --select <model>+`. Check that row count is within ±2% of baseline and the null rate is under threshold, and compare against `expected.json` (the contract check). Then re-run the Airflow task for the patched model.
- `pr.py`: create a branch, commit the patch, and write a PR body in markdown (root cause, evidence, verification log). Run `gh pr create` only when `--open` is passed. Dry-run is the default.
