## Live run safety net (prep, before the real key is used)

`pipeline_medic/llm.py` now guards real Meta Model API calls:

- The `OpenAI` client is built with `max_retries=0` and `timeout=120` — no silent SDK-level retries against a paid endpoint.
- A hard cap, `MAX_LLM_CALLS` (default 20), is enforced via an on-disk counter at `.cache/llm/calls.json`. Every real call attempt counts, including the invalid-JSON retry. Once the cap is hit, `diagnose()` raises `LLMCallCapError` before touching the network. Raise `MAX_LLM_CALLS` to allow more calls in one run.
- Every real call appends one line to `.cache/llm/usage.jsonl`: timestamp, scenario (if known), model, prompt/completion/reasoning tokens, and an estimated cost at $1.25/M input + $4.25/M output tokens. Cache hits make no call and add no usage line. The key, headers, and full prompts are never logged.

`pipeline-medic run --save-artifacts DIR` writes, per scenario, `report.txt` (the rendered rich report), `diagnosis.json`, and `verify.log`, plus a copy of `summary.html` at the top of `DIR`. Every artifact is scrubbed first: the literal `MODEL_API_KEY` value and anything matching `Bearer \S+` are replaced with `[REDACTED]`.

Check `.cache/llm/usage.jsonl` afterwards for the actual spend, and `.cache/llm/calls.json` for the running call count against `MAX_LLM_CALLS`.
